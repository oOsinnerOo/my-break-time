# my-break-time

ฟาร์มน้อยพักใจและระบบบันทึกเวลาพัก เปิดเล่นฟาร์มได้ที่
[ฟาร์มน้อยพักใจ](https://oosinneroo.github.io/my-break-time/?farm)

## ฟาร์มเดินเล่น

- แตะพื้นเพื่อเดิน ตัวละครจะหาเส้นทางอ้อมอาคาร แปลง และสิ่งกีดขวาง
- แตะอาคารหรือแปลง แล้วกดใช้งานเมื่อเดินถึง ใช้แปลง ผลผลิต คลัง และระบบเดิมจริง
- มือถือมีปุ่มทิศทาง คอมพิวเตอร์ใช้ลูกศรหรือ WASD และ Enter ได้เมื่อโฟกัสแผนที่
- ปุ่มตัวละครใช้เปลี่ยนสีเสื้อ สีผม และหมวก ตำแหน่งกับชุดบันทึกในเซฟฟาร์ม
- จัดพื้นที่เพื่อย้ายอาคารและสร้างทางเดิน รั้ว ม้านั่ง แปลงดอกไม้ หรือโคมไฟด้วยวัตถุดิบ
  ระบบกันวางทับแปลง และกันปิดทางเข้าอาคาร เก็บของตกแต่งคืนได้วัตถุดิบเดิม
- ต้นไม้และกองหินในที่ดินเคลียร์ได้ครั้งเดียว ใช้แรง 1 หน่วย ได้ไม้หรือหิน 2 ชิ้น
- ขยายที่ดินผ่านราคาและเลเวลของระบบเดิม สูงสุด 6 ครั้ง เพิ่มแปลงครั้งละ 1 แปลง
  ครั้งแรกเปิดพื้นที่ใต้ฟาร์ม ครั้งที่ 4 เปิดพื้นที่ตะวันออก
- สลับกลับสวนพักใจเพื่อใช้มุมมองต้นไม้และการแต่งสวนเดิมได้

## ชาวบ้านที่มีชีวิตและสมุดภารกิจ

- ชาวบ้านเดิมทั้ง 8 ตัวมาเดินในฟาร์มเป็น Pixel Art มีเส้นทางหลบอาคาร แปลง และสิ่งกีดขวาง
  ทำงาน แวะตลาด พักริมบ่อ และกลับมาพักหน้าบ้านตามนาฬิกาหมู่บ้าน (1 วัน = 24 นาทีจริง)
  วันที่ฝนตกจะเดินไปหลบใต้ชายคา วันที่ร้อนจัดจะพักริมบ่อ พร้อมท่าทำงานและท่าพัก
- แตะชาวบ้านหรือเลือกจาก **สมุดชาวบ้าน → ชาวบ้าน** เพื่อเดินไปคุย ตัวละครจะหยุดรอ
  อยู่ใกล้แล้วกดคุย รับภารกิจ ให้ของขวัญ หรือส่งงานได้
- เพิ่มเรื่องราวส่วนตัว 8 เรื่อง เรื่องละ 3 ขั้น: คุยหาเบาะแส ตามหาของในแผนที่
  สำรวจสถานที่ และรวบรวมของกลับมาส่ง NPC แต่ละคนมีบทพูดหลังจบเรื่องของตนเอง
- ติดตามงานพร้อมกันได้ 3 งาน ปุ่ม **ไปหา** เดินไปยังเป้าหมายขั้นปัจจุบัน
  พักเรื่องราวส่วนตัวแล้วกลับมาทำต่อจากขั้นเดิมได้ ของภารกิจไม่ใช้พื้นที่ยุ้งฉาง
- มีคำขอประจำวันจากชาวบ้าน ส่งรับรางวัลรวมได้วันละ 3 งาน งานที่รับแล้วไม่หมดอายุ
  และคืนคำขอได้ก่อนส่งโดยไม่มีวัตถุดิบถูกหัก
- คุยกันครั้งแรกของวันได้ความสนิท +2 ให้ของขวัญได้วันละ 1 ชิ้นต่อคน
  ของโปรด +6 ของอื่น +2 ความสนิทเต็ม 5 หัวใจ ปลดล็อกความทรงจำที่ 1 และ 3 หัวใจ
  การคุย ของขวัญ และจำนวนคำขอรายวันรีเซ็ตตามวันจริงของเกม
- เควสต์หมู่บ้าน 8 บทเดิมยังส่งผ่านหน้าต่างเดิมหรือ NPC เจ้าของงานได้
  ความคืบหน้าภารกิจส่วนตัว ความสนิท และของขวัญที่ให้แล้วบันทึกในเซฟฟาร์มและไฟล์สำรอง
- หักของจากคลังจริงเมื่อส่งงาน ใช้ของดาวต่ำก่อน และบันทึกการรับรางวัลเพื่อกันกดซ้ำ

## เดินเจอเพื่อนในห้อง

- เข้าห้องเดียวกันผ่านเมนูเพื่อน แล้วแต่ละคนเปิดปุ่ม **ห้องเพื่อน** บนฟาร์ม
- ลานกลางใช้แผนที่เดียวกัน เห็นชื่อ ชุด และการเดินของเพื่อนที่เปิดลานอยู่แบบสด
- แตะตัวละครหรือชื่อเพื่อนเพื่อเดินไปหา เมื่ออยู่ใกล้กันจะโบกมือ ดูฟาร์ม หรือเปิดส่งของขวัญได้
  ใช้ระบบเยี่ยมฟาร์มและของขวัญเดิมของห้อง
- อาคารในลานเปิดตลาดเพื่อน ภารกิจทีม หมู่บ้าน ข่าว บอส และกิจกรรมของห้องได้
- รองรับปุ่มทิศทางบนมือถือ ลูกศรหรือ WASD และ Enter บนคอมพิวเตอร์
- เมื่อเน็ตสะดุดจะพยายามเชื่อมต่อใหม่ และแสดงตำแหน่งสำรองพร้อมป้าย **ตำแหน่งล่าสุด**
  เพื่อนที่ไม่ได้ส่งข้อมูลเกิน 45 วินาทีจะหายจากลานจนกว่าจะกลับมา
- ชุดใช้ชุดที่เลือกไว้ในฟาร์ม ส่วนตำแหน่งในลานแยกจากตำแหน่งในฟาร์มส่วนตัว
  ข้อมูลการเดินส่งเฉพาะตำแหน่ง ทิศทาง และชุด ไม่ส่งรหัสลับห้อง คลัง หรือสถิติเวลาพัก

## คิวแปรรูป

แต่ละเครื่องรองรับ 10 งานรวมงานกำลังทำ งานรอ และงานที่เสร็จแล้ว เลือกหลายงานหรือ
ผสมสูตรในคิวได้ เครื่องทำต่ออัตโนมัติและนับเวลาขณะปิดเกม วัตถุดิบถูกหักเมื่อเพิ่มคิว
ยกเลิกได้เฉพาะงานที่ยังไม่เริ่ม และคืนคุณภาพดาวเดิมครบ รับของแยกเครื่องหรือรับทั้งหมดได้
ถ้าคลังเต็ม ของที่รับไม่ได้จะยังอยู่ในเครื่อง งานเดิมก่อนอัปเดตจะถูกย้ายมาให้ต่อเนื่อง

## ตรวจสอบระบบ

โปรเจกต์เป็นเว็บแบบ static ไม่ต้องติดตั้งแพ็กเกจ รันการตรวจคิว เซฟ แผนที่ และเครือข่ายห้องด้วย Node.js:


## ประมูลและต่อรองกับชาวบ้าน

- ผู้ประมูลแต่ละคนมีงบและของที่สนใจ ทยอยเสนอจริงเป็นรอบ บันทึกประวัติราคาไว้
  ปิดเว็บแล้วกลับมาจะจำลองรอบที่ขาดไปต่อจากสถานะเดิม ไม่สุ่มราคาปิดใหม่
- เมื่อคุณนำจะพักเหรียญไว้ หาก NPC เสนอแซงจะคืนเหรียญให้ครั้งเดียว
  เสนอในนาทีสุดท้ายต่อเวลาได้รวมไม่เกิน 2 นาที ของที่คุณนำอยู่ไม่ถูกทิ้งเมื่อขึ้นวันใหม่
- ลูกค้าต่อราคาตามมูลค่าตลาด ความชอบและชื่อเสียงร้าน ไม่อิงป้ายราคาที่ตั้งสูงตามใจ
  คุยเป็นรอบ มีคำตอบเมื่อถึงงบสุดท้าย ปฏิเสธอย่างสุภาพได้ และรับข้อเสนอที่หมดเวลาไม่ได้

## เส้นทางและอุปกรณ์สำรวจ

ป่าเลือกเส้นทางตัดไม้หรือสมุนไพร เหมืองเลือกสายแร่หรือตามรอยทางลง
ชายหาดเลือกเก็บของน้ำพัดหรือดูแลชายหาด ทุกเส้นทางมีเป้าหมายและรางวัลครั้งเดียวต่อรอบ
เก็บของไว้แล้วกลับบ้านก่อนได้ และเริ่มพื้นที่ใหม่หลังจบรอบเดิมเพื่อรักษาของที่ติดตามระหว่างเดินทาง

อุปกรณ์ใหม่ในแท็บอัปเกรด: ถุงมือลดความเสียหาย ตะเกียงบอกจุดแร่ปลอดภัย
และแผนที่น้ำขึ้นน้ำลงบอกของใต้ทราย/เพิ่มจำนวนตกปลา แต่ละชิ้นมี 3 ระดับ
ร้านค้าแท็บอุปกรณ์มีผ้าพันแผล เชือกเปิดทางลงเหมือง และไม้แห้งสำหรับผู้เล่นช่วงต้น
ซื้อของเป็นชุดต้องมีช่องเก็บพอ ของรางวัลที่เกิน 999 จะเก็บในตู้สำรองและเติมกลับเมื่อใช้ของ

## ป้ายรับซื้อในห้องเพื่อน

เปิดแผงขาย → ตลาดเพื่อน → ตั้งป้ายรับซื้อ เลือกไอเทม ดาว จำนวน 1–99 และราคาต่อชิ้น
ระบบพักเงินทั้งป้ายและประกาศในข่าวห้อง เพื่อนขายให้ได้ทันทีตามจำนวนของที่มี
รองรับการขายบางส่วน เปิดพร้อมกัน 6 ป้าย อยู่ได้ 3 วัน ยกเลิก/หมดเวลา/ออกจากห้องคืนเงินส่วนที่ยังไม่ได้ซื้อ

ตารางอยู่ใน schema ส่วนตัว `breaktime` เปิด RLS และไม่ให้ client อ่านตารางโดยตรง
RPC ตรวจ player/secret และห้องตามระบบเดิม ใช้ row lock กันขายชนกัน และ operation UUID กันส่งซ้ำ
ฝั่งเกมบันทึก outbox ก่อนหักของ/เงินและ retry รายการเดิมเมื่อเน็ตขาด
รับของ/เหรียญด้วย receipt ID ที่บันทึกก่อน ACK จึงรับซ้ำหรือรับใบเก่าที่เพิ่ง commit ภายหลังได้อย่างถูกต้อง
การบันทึกเงินและฟาร์มใหม่ใช้ write-ahead journal กู้ให้ครบทั้งสองเซฟหลังปิดหน้าระหว่างบันทึก

SQL และชุดตรวจการซื้อขายอยู่ใน `supabase/migrations/` และ `supabase/tests/wanted.sql`
ตรวจบนฐานข้อมูลเดียวกับห้องเดิมก่อนเผยแพร่ frontend ไม่ต้องเพิ่ม secret key ในเว็บ
เกมยังใช้เหรียญและคลังในเซฟผู้เล่นตามโครงสร้างเดิม จึงไม่ได้ป้องกันการแก้เซฟโดยเจ้าของเครื่อง
